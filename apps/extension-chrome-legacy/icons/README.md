# 图标文件说明

## 图标规格
- **icon16.png**: 16x16 像素，用于浏览器工具栏
- **icon48.png**: 48x48 像素，用于扩展管理页面  
- **icon128.png**: 128x128 像素，用于应用商店展示

## 图标要求
- 格式: PNG
- 背景: 透明或白色
- 风格: 简洁现代，与 Pintia 平台风格协调
- 颜色: 蓝色主题 (#2196F3)

## 临时解决方案
由于当前没有设计图标，可以使用以下临时方案：

1. 创建简单的蓝色圆形图标
2. 使用文字"WPH"作为图标内容
3. 或者使用编程相关的简单图标（如{}符号）

## 图标生成工具推荐
- Figma (免费在线设计)
- Canva (模板设计)
- Adobe Illustrator (专业设计)
- 在线图标生成器 (如: https://www.favicon-generator.org/)

## 注意事项
- 确保图标在不同尺寸下都清晰可辨
- 保持图标风格一致性
- 考虑深色模式下的显示效果
