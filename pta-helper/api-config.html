📖 使用说明

  • 获取密钥：登录腾讯云控制台，在访问管理-API密钥管理中创建密钥
  • 模型说明：使用腾讯云混元-lite模型，具有高性价比和快速响应特点
  • 费用说明：混元-lite模型按调用次数计费，新用户通常有免费额度
  • 隐私保护：所有配置信息仅存储在本地浏览器中，不会上传到任何服务器
  • 缓存机制：相同题目的答案会缓存5分钟，减少API调用次数

💡 快速开始

  1. 访问腾讯云API密钥页面
  2. 点击"新建密钥"创建SecretId和SecretKey
  3. 将密钥信息填入上方表单
  4. 点击"测试连接"验证配置
  5. 保存配置后即可在PTA页面使用AI答题功能
