# PTA答题助手 - 版本历史记录

## v2.0.0 (2025-10-26)
### 主要特性
- **现代化架构重构**：基于Monorepo的多包管理
- **TypeScript支持**：完整的类型安全
- **工程化工具链**：ESLint + Prettier + Husky
- **模块化设计**：核心包、工具包、配置包分离
- **测试框架**：Vitest单元测试和集成测试

### 技术栈升级
- 包管理：pnpm + Lerna
- 构建工具：Vite + Father
- 前端框架：React 18 + TypeScript
- UI组件库：Ant Design
- 文档工具：Dumi

## v1.2.0 (2025-10-25)
### 功能增强
- **智能答案匹配**：基于编辑距离的相似度算法
- **扩展题目类型**：新增网络基础、数据库、操作系统、软件工程
- **增强错误处理**：内容脚本自动重注入机制
- **UI优化**：浮动工具栏智能显示控制

### 新增特性
- 编程题检测和自动填充
- AI服务集成（腾讯云混元大模型）
- 实时统计信息显示
- 快捷键支持（Ctrl+Shift+D/F/H）

## v1.1.0 (2025-10-24)
### 核心功能完善
- **浮动工具栏**：可拖拽、最小化、状态指示
- **弹出界面**：详细控制面板和设置选项
- **答案数据库**：结构化分类存储
- **题目检测**：支持多种题型识别

### 用户体验改进
- 视觉反馈系统（颜色编码）
- 状态通知机制
- 响应式设计
- 错误处理和调试模式

## v1.0.0 (2025-09-20)

- **基础功能**：题目检测、答案填充、提交答案

## 技术架构演进

### 架构1.0 (v1.x)
```
单文件结构
├── content.js      # 内容脚本
├── popup.js        # 弹出界面
├── background.js   # 后台服务
└── 其他辅助文件
```

### 架构2.0 (v2.x)
```
Monorepo结构
├── packages/
│   ├── core/       # 核心扩展包
│   ├── utils/      # 工具函数包
│   └── config/     # 配置包
├── 配置文件
└── 文档和测试
```
