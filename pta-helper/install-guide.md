# PTA答题助手 - 安装使用指南 📖

## 🚀 快速安装

### 步骤1：下载插件
确保您已经获得了完整的 `pta-helper` 文件夹，包含以下文件：
```
pta-helper/
├── manifest.json          ✅ 插件配置文件
├── popup.html             ✅ 弹出界面
├── popup.css              ✅ 弹出界面样式
├── popup.js               ✅ 弹出界面逻辑
├── content.js             ✅ 核心功能脚本
├── content.css            ✅ 页面样式
├── background.js          ✅ 后台服务
├── answer-database.js     ✅ 答案数据库
├── utils.js               ✅ 工具函数
└── icons/                 📁 图标文件夹
```

### 步骤2：打开Chrome扩展程序管理页面
1. 打开Chrome浏览器
2. 在地址栏输入：`chrome://extensions/`
3. 按回车键进入扩展程序管理页面

### 步骤3：开启开发者模式
在扩展程序页面的右上角，找到"开发者模式"开关并开启它。

### 步骤4：加载插件
1. 点击"加载已解压的扩展程序"按钮
2. 在文件选择对话框中，选择 `pta-helper` 文件夹
3. 点击"选择文件夹"

### 步骤5：验证安装
安装成功后，您应该能看到：
- 扩展程序列表中出现"PTA答题助手"
- 浏览器工具栏中出现插件图标
- 状态显示为"已启用"

## 🎯 首次使用

### 1. 访问PTA网站
打开浏览器，访问 https://pintia.cn 并登录您的账号。

### 2. 进入答题页面
选择任意考试、练习或作业，进入答题界面。

### 3. 查看插件状态
页面加载完成后，您应该能看到：
- **浮动工具栏**：页面右上角的紫色渐变工具栏
- **状态通知**：右上角显示"PTA答题助手已启动"的通知

### 4. 开始使用
- 点击工具栏中的"🔍 检测题目"按钮
- 观察题目被高亮标记
- 点击"✨ 自动填充"按钮填充答案

## ⌨️ 快捷键使用

插件支持以下快捷键（在PTA页面中使用）：

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 检测题目 | `Ctrl+Shift+D` | 快速检测页面中的所有题目 |
| 自动填充 | `Ctrl+Shift+F` | 自动填充检测到的题目答案 |
| 隐藏工具栏 | `Ctrl+Shift+H` | 隐藏或显示浮动工具栏 |

## 🎨 界面说明

### 浮动工具栏
- **位置**：页面右上角
- **移动**：拖拽标题栏可以移动位置
- **最小化**：点击"−"按钮最小化工具栏
- **统计信息**：显示检测数量、填充数量、成功率

### 弹出界面
点击浏览器工具栏中的插件图标，可以打开详细的控制面板：
- 页面状态检测
- 功能按钮
- 设置选项
- 快捷键提示

### 视觉反馈
- **绿色边框**：已检测的题目
- **蓝色边框**：已填充答案的题目
- **通知消息**：操作结果的实时反馈
- **状态指示器**：彩色圆点显示当前状态

## 🔧 常见问题

### Q1: 插件无法加载怎么办？
**A**: 检查以下几点：
1. 确保开启了开发者模式
2. 检查文件夹是否完整
3. 查看是否有错误提示
4. 尝试重新加载插件

### Q2: 在PTA页面看不到工具栏？
**A**: 可能的原因：
1. 页面还在加载中，请等待几秒
2. 检查是否在正确的PTA域名下
3. 按 `Ctrl+Shift+H` 尝试显示工具栏
4. 刷新页面重新加载插件

### Q3: 检测不到题目？
**A**: 尝试以下方法：
1. 确保页面完全加载完成
2. 检查是否在答题页面（不是题目列表页）
3. 手动点击"检测题目"按钮
4. 查看浏览器控制台是否有错误信息

### Q4: 答案填充不准确？
**A**: 这是正常现象：
1. 插件基于内置数据库匹配答案
2. 对于新题目可能无法准确匹配
3. 可以手动编辑 `answer-database.js` 添加新答案
4. 建议在练习模式下先测试准确性

### Q5: 如何更新插件？
**A**: 更新步骤：
1. 下载新版本的插件文件
2. 在扩展程序页面点击"刷新"按钮
3. 或者删除旧版本，重新加载新版本

## 🛠️ 高级设置

### 自定义答案数据库
编辑 `answer-database.js` 文件，在相应分类中添加题目和答案：

```javascript
// 示例：添加新的计算机基础题目
computer_basics: {
    '你的题目文本': '对应的答案',
    '另一个题目': '另一个答案'
}
```

### 修改界面样式
- 编辑 `content.css` 修改浮动工具栏样式
- 编辑 `popup.css` 修改弹出界面样式

### 调试模式
1. 按 `F12` 打开开发者工具
2. 在 Console 标签中查看插件日志
3. 检查是否有错误信息
