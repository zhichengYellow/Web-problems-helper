# PTA答题助手 - 项目说明

```
apps/extension-chrome-legacy/
├── manifest.json          # Chrome 插件配置文件
```

## 🚀 快速开始

### 后端服务启动（可选）

如果需要使用腾讯云hunyuan-lite AI模型功能，需要先启动后端服务：

#### 前置要求
- Node.js v16 或更高版本
- 建议使用 nvm 管理 Node.js 版本

#### 启动步骤

#### 快速启动（推荐）

使用项目提供的启动脚本，一键启动后端服务：

```bash
# 在项目根目录运行
./scripts/start-backend-node.sh
```

启动脚本会自动：
- 使用nvm切换到正确的Node.js版本
- 安装依赖（首次运行）
- 检查环境配置文件
- 启动开发模式

#### 手动启动（可选）

1. **切换到后端目录**
   ```bash
   cd apps/backend-node-compat
   ```

2. **使用 nvm 切换到正确的 Node.js 版本**
   ```bash
   # 如果已安装 nvm
   source ~/.nvm/nvm.sh
   nvm use 22

   # 如果未安装 nvm，请先安装
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
   ```

3. **安装依赖**
   ```bash
   npm install
   ```

4. **启动服务**
   ```bash
   # 生产环境
   npm start

   # 开发环境（自动重启）
   npm run dev
   ```

5. **验证服务状态**
   ```bash
   # 健康检查
   curl http://localhost:3001/health

   # 查看服务状态
   curl http://localhost:3001/status
   ```

#### 服务信息

| 项目 | 信息 |
|------|------|
| 服务名称 | Tencent Cloud Hunyuan Proxy Server |
| 端口 | 3001 |
| 基础URL | http://localhost:3001 |
| 健康检查 | http://localhost:3001/health |
| 聊天API | http://localhost:3001/api/chat |

#### 后端功能

后端服务提供以下功能：
- **CORS跨域处理**: 解决浏览器跨域问题
- **API签名验证**: 自动处理腾讯云API签名
- **批量请求支持**: 支持批量题目处理
- **默认密钥配置**: 可在 `server/.env` 中配置默认API密钥

#### 环境配置

在 `server/.env` 文件中配置腾讯云API密钥：

```bash
# 腾讯云 API 密钥配置
TENCENT_SECRET_ID=your_secret_id_here
TENCENT_SECRET_KEY=your_secret_key_here

# 服务端口
PORT=3001
```

#### 停止服务

在运行终端按 `Ctrl+C` 停止服务，或使用以下命令：

```bash
# 查找并停止进程
ps aux | grep "node index.js"
kill <PID>
```

### 1. 安装插件
1. 打开Chrome浏览器
2. 访问 `chrome://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `pta-helper` 文件夹

### 2. 使用插件
1. 访问 https://pintia.cn
2. 进入考试/作业/练习页面
3. 点击浏览器工具栏中的插件图标
4. 使用插件功能进行答题
