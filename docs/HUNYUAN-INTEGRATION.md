# 腾讯云hunyuan-lite模型集成指南

## 📋 概述

本文档介绍如何在PTA答题助手中集成和使用腾讯云hunyuan-lite大语言模型，提供更智能的题目答案搜索功能。

## 🚀 快速开始

### 1. 获取腾讯云API密钥

1. 访问 [腾讯云控制台](https://console.cloud.tencent.com/)
2. 进入「访问管理」→「API密钥管理」
3. 创建新的SecretId和SecretKey
4. 确保开通了「hunyuan-lite」服务的访问权限

### 2. 配置hunyuan-lite

#### 方式一：网页配置（推荐）
1. 打开 `hunyuan-setup.html` 文件
2. 输入您的腾讯云SecretId和SecretKey
3. 点击保存配置
4. 配置将自动保存到浏览器本地存储

#### 方式二：配置文件
1. 复制 `config-example.js` 为 `config.js`
2. 填入您的实际SecretId和SecretKey
3. 保存文件

#### 方式三：插件配置界面
1. 打开PTA答题助手配置界面（点击插件图标→配置）
2. 在API设置中选择「腾讯云hunyuan-lite」
3. 输入您的SecretId和SecretKey
4. 点击「保存配置」

### 3. 开始使用

1. 访问PTA平台进入题目页面
2. 插件会自动使用hunyuan-lite模型分析题目
3. 获取智能生成的答案

## ⚙️ 详细配置

### API配置参数

| 参数 | 说明 | 必填 |
|------|------|------|
| SecretId | 腾讯云API访问密钥ID | 是 |
| SecretKey | 腾讯云API访问密钥 | 是 |

### 模型特性

- **模型名称**: hunyuan-lite
- **支持题型**: 选择题、判断题、简答题
- **响应速度**: 快速（通常1-3秒）
- **准确率**: 基于大语言模型的智能推理

## 🔧 故障排除

### 常见问题

1. **API调用失败**
   - 检查SecretId和SecretKey是否正确
   - 确认腾讯云账户有足够的余额
   - 检查网络连接是否正常

2. **配置不生效**
   - 确保已选择「腾讯云hunyuan-lite」作为当前API
   - 重启浏览器使配置生效

3. **响应超时**
   - 检查网络连接
   - 尝试降低题目复杂度

### 错误代码

| 错误代码 | 说明 | 解决方法 |
|----------|------|----------|
| AuthFailure | 认证失败 | 检查API密钥是否正确 |
| InvalidParameter | 参数错误 | 检查请求参数格式 |
| RequestLimitExceeded | 请求频率超限 | 降低调用频率 |
| ResourceUnavailable | 资源不可用 | 检查服务是否开通 |

## 💡 使用建议

### 最佳实践

1. **选择题优化**: 提供完整的题目和选项信息
2. **判断题**: 直接询问"正确"或"错误"
3. **复杂题目**: 拆分成多个简单问题

### 性能优化

- 启用本地缓存减少API调用
- 使用智能回退机制确保服务可用性
- 定期清理缓存数据
