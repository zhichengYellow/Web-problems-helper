# PTA答题助手 - 外部API集成指南

## 📋 概述

本插件现在支持通过外部API（如SH-API）作为题库和答案来源，增强答题功能的准确性和覆盖范围。

## 🔧 支持的API服务

目前支持以下API服务：
- **SH-API** (https://api.sh-api.com/v1)
- 其他兼容的题库API服务

## ⚙️ 配置步骤

### 1. 获取API密钥
1. 访问相应的API服务商网站
2. 注册账号并获取API密钥
3. 通常需要购买相应的服务套餐

### 2. 配置插件
1. 点击插件图标打开控制面板
2. 点击"API配置"按钮
3. 在配置页面中输入：
   - **API密钥**: 您的API密钥
   - **API基础地址**: API服务的URL（默认: https://api.sh-api.com/v1）
   - **启用API服务**: 勾选以启用

### 3. 测试连接
1. 点击"测试连接"按钮
2. 确认连接状态显示"✅ API连接正常"
3. 保存配置

## 🚀 使用说明

### 自动模式
- 启用API服务后，插件会优先从外部API搜索答案
- 如果API未找到答案，会回退到本地数据库匹配
- 答案会自动缓存5分钟，避免重复请求

### 手动模式
1. 点击"检测题目"识别页面中的题目
2. 点击"自动填充"使用API搜索并填充答案
3. 确认无误后点击"提交答案"

## 💡 功能特点

### 智能答案匹配
- 支持多种题型：单选题、多选题、判断题、填空题、编程题
- 智能关键词匹配和语义分析
- 批量题目处理能力

### 性能优化
- 答案缓存机制（5分钟有效期）
- 批量请求处理
- 连接失败自动回退

### 用户反馈
- 自动提交用户答案用于机器学习改进
- 答案正确性反馈机制

## 🔒 隐私和安全

- API密钥本地存储，不会上传到其他服务器
- 所有API请求使用HTTPS加密
- 用户答案反馈可选，默认不启用

## 🛠️ 故障排除

### 常见问题

**Q: API连接测试失败**
A: 检查API密钥是否正确，网络连接是否正常

**Q: API搜索不到答案**
A: 可能是题目不在API题库中，会回退到本地匹配

**Q: 答案填充错误**
A: 可以通过反馈机制提交正确答案

### 调试方法
1. 打开浏览器开发者工具（F12）
2. 查看Console标签页的错误信息
3. 检查Network标签页的API请求状态

## 📊 统计信息

- 平均响应时间
- 缓存命中率
